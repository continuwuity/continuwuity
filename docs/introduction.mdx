# Continuwuity

</div>

## What is Continuwuity?

Continuwuity is a Matrix homeserver. [Matrix] is an open chat network that lets anyone talk to anyone, no matter what server or address they use - like email.

Continuwuity receives and keeps track of all your messages, and delivers what you send to the right people.

[Matrix]: https://matrix.org

## Why is Continuwuity different?

Continuwuity is light and fast, using a fraction of the resources of other major homeservers. It's also simple to set up, and secure by default.

We are a community-run project, made up of friendly and diverse people. Everything is built by people who care about the project volunteering their free time.

## Try it out!

If you want to try it out as a user, we have some [partnered homeservers](./community/ops-guidelines.mdx) you can use:

**`federated.nexus`** - A community resource hosting multiple FOSS (especially federated) services.
- Go to https://federated.nexus, click on "Apply to Join", and follow the prompts.
- Once your request has been accepted, you will receive an email with your username and password, which you can use to sign in from any Matrix client.
- Remember to change your password after logging in!

**`continuwuity.rocks`** - the demo server, run by us.
- Sign up using any Matrix client, or via this [convenient link][cinny-register] for Cinny.

[cinny-register]: https://app.cinny.in/register/continuwuity.rocks
